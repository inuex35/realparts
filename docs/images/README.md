# docs/images

Pictures used by the README and the pages in `docs/`. All of them are
rendered from the shipped examples by the scripts in `tools/render/`, so a
change to an example or to the renderer should be followed by re-rendering
the image, not by editing it.

| image | shows | used by |
|---|---|---|
| `assembly.png` | `examples/assembly.json`, bracket and bush mated | output.md |
| `bottle.png`, `fairing.png`, `sheet_bracket.png` | the bottle, the lofted fairing and the sheet metal bracket | features.md |
| `flange.png` | the bolted flange | addon.md |
| `addon-cup.png`, `addon-sketch.png`, `addon-studies.png` | the Blender sidebar in three states | addon.md |
| `walk.gif` | the quadruped walking | quadruped.md |
